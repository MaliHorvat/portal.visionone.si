VisionOne — monitoring agent (Raspberry Pi / CMD)
=================================================

KAJ DELA
  - Prebere IP-je kamer, NVR in stikal iz portala (pod stranko).
  - Pinga naprave (TCP na port, npr. 554 za kamero).
  - Pošlje stanje v portal → stranka vidi na moj.visionone.si → Stanje sistema.

PREDPOGLED V TERMINALU (Raspberry Pi)
  sudo systemctl status visionone-agent
  sudo journalctl -u visionone-agent -f

  Ročno en cikel z jasnim izpisom:
  sudo python3 /opt/visionone-agent/visionone_agent.py --once

  Stalno delovanje (zanka):
  sudo python3 /opt/visionone-agent/visionone_agent.py

  Zeleno OK = naprava dosegljiva
  Rdeč IZPAD = naprava ni dosegljiva
  Exit code 0 = vse OK, 1 = težava

NAMESTITEV NA RASPBERRY (priporočeno)
  1. V portalu: Stranka → Care Box → Prenesi paket za Raspberry Pi
  2. SD kartica z Raspberry Pi Imager + kopija boot/ in opt/ iz ZIP
  3. Po vklopu: agent se sam namesti (systemd visionone-agent)

PORTAL — PRED POGONOM
  - Na stranki morajo biti vpisani IP-ji kamer/NVR (zavihek Kamere / Oprema).
  - Agent mora biti dodeljen stranki (Care Box ali bundle).
  - Vercel: ESP_INGEST_TOKEN mora biti nastavljen.

TEST NA WINDOWS (CMD)
  1. agent-rpi\opt\visionone-agent\agent.json.example → agent.json
  2. Vpišite portal_base_url, token, agent_id
  3. Zaženite agent-rpi\ZAŽENI-AGENT.cmd

STRANKA (moj.visionone.si)
  Meni → Stanje sistema — zeleno/rdeče po napravah, brez RTSP.
